# Design

## Context

Сервис хранит исходные изображения в PostgreSQL. Для первого запуска нужны Docker с Compose и две команды из корня репозитория.

## Goals / Non-Goals

**Goals**

- Реализовать три операции с единым правилом авторизации и предсказуемыми HTTP-ответами.
- Сохранять файлы при пересоздании контейнера и закрыть основные сценарии тестами.

**Non-Goals**

- Очередь сообщений и генерация уменьшенных копий.

## Decisions

- `app/main.py` настраивает FastAPI и подключает `APIRouter` из `app/api.py`. Асинхронная зависимость маршрутизатора проверяет ключ. Маршруты валидируют HTTP-вход и сопоставляют ошибки с HTTP-статусами. `app/storage.py` принимает и проверяет поток, а `app/db.py` выполняет операции записи и чтения PostgreSQL. `app/config.py` читает настройки.
- Клиент передаёт исходный случайный ключ в `X-API-Key`. Compose передаёт приложению только `API_KEY_HASH` из `.env`. Приложение проверяет формат хеша при запуске, вычисляет SHA-256 от полученного ключа и сравнивает два хеша через `hmac.compare_digest`. Встроенные маршруты документации отключены, чтобы у API оставались только три защищённых маршрута.
- Клиент передаёт байты файла в теле `PUT /images/{name}`. `app/api.py` проверяет `Content-Length`, если он задан, до чтения тела. `Request.stream()` передаёт порции в `app/storage.py`, который считает фактически полученные байты и проверяет лимит до записи каждой порции. Переполнение прерывает чтение и даёт `413`.
- Поток пишется во временный файл, а Pillow выполняет проверку в рабочем потоке. После проверки приложение передаёт байты драйверу psycopg. Первичный ключ имени и `INSERT … ON CONFLICT DO NOTHING` исключают перезапись даже при параллельных загрузках. `201` выдаётся после фиксации транзакции.
- Скачивание получает байты одной записью и освобождает соединение перед отправкой тела по HTTP. Одновременное удаление не прерывает уже начатую выдачу.
- Compose запускает PostgreSQL с отдельным именованным томом, ждёт готовности базы и выполняет Alembic перед запуском API. Миграция переносит существующие файлы из прежнего тома, смонтированного только для чтения.
- Compose публикует порт 8000 на loopback. Вне локального окружения необходимы уникальный ключ и HTTPS.

## Risks / Trade-offs

- Лимит размера сжатого файла дополняется лимитом в 25 миллионов пикселей, чтобы ограничить расход памяти при декодировании.
- Драйвер читает одно поле `bytea` целиком. Память на файл ограничивает максимальный размер загрузки в 10 МиБ. База переживает обычный `docker compose down` за счёт именованного тома.
