# Proposal

## Why

Необязательная часть ТЗ «Тестовое AI Backend» предусматривает уменьшенные копии загруженных изображений. Клиенту нужна копия, которую можно получить после сохранения оригинала.

## What Changes

- После фиксации оригинала асинхронно публиковать событие в RabbitMQ через FastStream.
- Запускать отдельный воркер для создания и сохранения миниатюр в PostgreSQL.
- Добавить защищённый маршрут получения миниатюры. Сохранить текущий контракт операций с оригиналом.

## Capabilities

### New Capabilities

- `image-thumbnails` — фоновая генерация, получение и удаление миниатюр.

### Modified Capabilities

## Impact

FastAPI, асинхронные операции SQLAlchemy, миграция Alembic, RabbitMQ, воркер FastStream, Docker Compose, pytest и документация.
