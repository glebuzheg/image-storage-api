## MODIFIED Requirements

### Requirement: Надёжная постановка задания при загрузке

Воркер SHALL фиксировать записанный оригинал и задание на миниатюру в одной транзакции PostgreSQL. API SHALL асинхронно отправлять событие через FastStream в RabbitMQ и хранить задание до подтверждения доставки в устойчивую очередь.

#### Scenario: Брокер недоступен при загрузке

- **WHEN** клиент загружает допустимое изображение при недоступном RabbitMQ
- **THEN** API возвращает `202`, а после восстановления связи воркер записывает оригинал и назначает миниатюру

#### Scenario: Имя уже занято

- **WHEN** клиент загружает допустимое изображение под занятым именем
- **THEN** API возвращает `409`, сохраняя байты и задание победившей загрузки
